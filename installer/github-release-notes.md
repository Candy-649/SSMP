**下载下面 Assets 里的 silksong-coop-mod-{version}.zip**（不是 Source code）。

1. 解压到任意位置，比如桌面。
2. 双击 INSTALL.bat：它会找到游戏，先备份存档，再装好自带的 BepInEx 和联机插件。安装不联网。
3. 以后出了新版：先关掉游戏，再双击 UPDATE.bat，它会从 npm 下载最新的联机插件换上。

一起玩的人要装同一版。详细说明在包里的 INSTALL.txt。

在中国大陆从 GitHub 下载很慢的话，npmmirror 上有同一个包（.tgz 格式，用 7-Zip 或 Windows 11 自带的解压都能打开，里面的 package 文件夹就是这些东西）：
https://registry.npmmirror.com/silksong-coop-mod/-/silksong-coop-mod-{version}.tgz

Download **silksong-coop-mod-{version}.zip** from the assets below, unpack it anywhere and double-click INSTALL.bat. It finds the game, backs up your saves and installs the bundled BepInEx and the plugin, without going online. For a newer build later, close the game and double-click UPDATE.bat, which fetches it from npm. Everyone playing together needs the same version.
