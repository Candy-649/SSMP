丝之歌联机模组（SSMP 自制版）——安装说明
==========================================

这是 SSMP 联机模组的一个自制版本，比公开版多了「联机存档」：
几个人共用一条流程，任务、世界变化、剧情道具会互相同步。

重要：几个人必须装【同一个版本】，不能一个人用公开版。
加入房间时会比对版本，不一样就连不上，并且会告诉你「模组版本不同」。

【这个包是完全离线的】模组加载器已经放在包里，
安装过程不需要联网，不用梯子，也不受任何网站能不能打开的影响。


一、怎么装
----------

先看你拿到的是哪种包：
  - 从 N 网（Nexus）下载的 zip：里面直接就是 BepInEx 文件夹、winhttp.dll 这些，
    没有 INSTALL.bat。按下面的 A 装。
  - 从 npm 下载的包，或者里面有 INSTALL.bat 的包：按下面的 B 装。

A. 解压到游戏目录（N 网的包）

1. 先备份存档：把存档文件夹整个复制一份，放到别的地方。存档文件夹在
     C:\Users\你的用户名\AppData\LocalLow\Team Cherry\Hollow Knight Silksong
   AppData 是隐藏的文件夹，一层层点进去是找不到的。最省事的打开方法：按 Win+R，
   把下面这一行粘进去，回车：
     %USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight Silksong

2. 找到游戏目录（有 Hollow Knight Silksong.exe 的那个文件夹）：
   - 最准的办法：打开 Steam 的「库」，在 Hollow Knight: Silksong 上点右键 → 管理 → 浏览本地文件，
     弹出来的窗口就是游戏目录。
   - 装游戏时没改过位置的话，它在
       C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight Silksong
     游戏装在别的盘的话，一般在那个盘的 SteamLibrary\steamapps\common\Hollow Knight Silksong
     （比如 D:\SteamLibrary\steamapps\common\Hollow Knight Silksong）；Steam 本身装在别处的话，
     在那个 Steam 文件夹的 steamapps\common\Hollow Knight Silksong。

3. 把压缩包里的东西【全部】解压到这个文件夹里：BepInEx 文件夹、
   winhttp.dll、doorstop_config.ini、.doorstop_version、changelog.txt
   和这份 INSTALL.txt。问要不要覆盖，就选覆盖。

4. 装好以后，游戏目录里应该能直接看到这几样：
     Hollow Knight Silksong.exe
     winhttp.dll
     BepInEx\plugins\SSMP\SSMP.dll
   如果解压时多出了一层文件夹（比如 silksong-coop-mod-版本号\BepInEx），
   要把里面的东西挪出来，直接放在游戏目录下。

5. 从 Steam 启动游戏，主菜单里有 Start Multiplayer 就装好了。

B. 双击安装（npm 的包）

1. 把这个压缩包【完整解压】到任意位置（比如桌面）。
   不要只解压出单个文件，INSTALL.bat、SSMP 文件夹和
   BepInEx_win_x64_5.4.23.4 文件夹必须在一起。

2. 双击 INSTALL.bat。

3. 等它跑完，看到绿色的 Done 就好了。

它会自己做这几件事：
   - 找到你的 Silksong 安装位置（找不到会让你把路径粘进去）
   - 先把你的存档备份成 zip，放在这个文件夹里的 save-backups\ 下
     （只留最近 3 份，更旧的会自动删掉；它不会碰别的文件）
   - 用包里自带的加载器装好（不联网）
   - 把联机插件放进去
   - 最后检查一遍有没有装成功

窗口里的提示是英文的，因为 Windows 自带的 PowerShell 显示中文
经常是乱码，英文反而不会出错。


二、安全吗
----------

- N 网的包里没有任何脚本，只有模组文件和这份说明。
- npm 的包里的 INSTALL.bat 只往【游戏目录】写东西，外加一个存档备份。
  不改注册表、不改系统设置、不装任何后台程序、不联网。
- 不需要管理员权限（除非你的游戏装在 C:\Program Files 里）。
- 想卸载：把游戏目录里的 BepInEx 文件夹、winhttp.dll、
  doorstop_config.ini、.doorstop_version、changelog.txt
  删掉就完全干净了（N 网的包还会在那里放一份 INSTALL.txt，也一起删掉）。

包里的 BepInEx 文件（N 网的包里是 BepInEx 文件夹和 winhttp.dll 这些，npm 的包里
是 BepInEx_win_x64_5.4.23.4 文件夹），是 BepInEx 官方在 GitHub 上发布的原版压缩包
（BepInEx_win_x64_5.4.23.4.zip，638,940 字节）原样解压出来的，一个都没改。

有一点要提前说：BepInEx 这类模组加载器的工作方式，是在游戏
exe 旁边放一个 dll（就是 winhttp.dll），让游戏启动时连带加载它。
这是所有同类加载器的通用做法，但这个手法和某些恶意软件相同，所以
【杀毒软件有时会报毒】。看到告警是这个原因，不是模组在干别的。
（VirusTotal 上 60 多家杀毒软件里，只有 1 家报了这个 winhttp.dll。）

真正的风险不在系统，在存档：模组有可能弄坏存档，所以装之前要先备份。
npm 的包会自动备份；N 网的包请按上面 A 的第 1 步自己备份。


三、怎么一起玩
--------------

1. 【从 Steam 启动游戏】，不要直接双击 exe。

2. 一个人开房：选 "Steam" 那一页，点 Create Lobby。
   开完房不会直接进游戏，而是停在一个【等待室】里。

3. 房主在等待室里点 INVITE FRIEND，会直接弹出 Steam 的邀请框，
   不用自己去找 Steam 覆盖层。对方接受邀请就会进到同一个等待室。
   不走 Steam 也有同样的等待室：
   · 「匹配大厅」页点「创建房间」：等待室里写着房间 ID，点「复制房间 ID」发给对方，
     对方在「匹配大厅」页的「房间 ID」里填上，点「连接」。
   · 「直连 IP」页点「创建」：等待室里写着端口，把你的 IP 和这个端口告诉对方，
     对方在「直连 IP」页填上，点「连接」。

4. 两个人各自点一次 I'M READY。
   名单上能看到对方是 READY 还是 NOT READY。
   【两个人都 READY 之后】，两边才会同时打开各自的选存档界面。
   反悔就再点一次取消。

5. 选存档，不用按任何键。
   · 房主选的存档就是大家一起玩的世界。有人加入后，房主的存档自动变成「联机存档」，聊天框里会说一声。
   · 加入的人选哪个存档都行，空的存档槽也行。选了以后先接收房主的存档
     （房主还没进存档的话，会等房主进了再继续），把你选的存档按房主的进度对齐，再进游戏。
     对齐之前，你这个存档会先备份一份（备份在哪见第四节）。
     对齐的规则：
       - 照房主的：打过的 Boss、遭遇战、剧情进度、NPC 的状态、门/拉杆/捷径/墙/升降机/付费机关/长椅/钥匙门、
         接了和完成了的祈愿（包括交过的东西）。进游戏时你坐在房主上次坐的长椅上。
       - 只加不减（房主有的你也会有，你自己多的照样留着）：能力、面具和灵丝的升级、
         在世界里找到或打 Boss 拿到的工具和纹章、钥匙、剧情道具、纪念品、在世界里捡到的地图、
         救出的跳蚤、图鉴。
       - 各归各的：钱、念珠串和碎片包、材料、消耗品、祈愿要收集的东西、送货的货、商店买的东西、
         花钱请人升级的东西、装备搭配、遗物、和人说过的话、自己画的地图、茧、小游戏的分数。
       - 房主完成了、你没完成过的祈愿：你直接拿到这个祈愿的奖励（钱也给）。
   · 这几种情况会先提醒你，再选一次同一个存档才进：
       - 这个存档原来不是联机存档，而且已经玩过（怕你选错了自己的单人存档）；
       - 这个存档打过房主还没打的 Boss：对齐后这些 Boss 会回来，要重新打，以前拿到的东西还是你的；
       - 房主玩的是死一次存档就没了的模式，而你用的是空存档槽：新存档也会是这个模式。
     提醒之后房主又玩出了新进度，再选时提醒的内容变了，会按新的内容再提醒一次。
   · 用玩过的存档加入时，游戏模式要和房主的一样，不一样不让进。
   · 只在进存档这一下对齐。进了游戏以后：门、机关、Boss 这些照旧实时同步，捡东西各捡各的。
   · 三个人以上也一样：每个加入的人都按房主对齐。

6. 联机存档要【至少两个人】才能玩：
   · 自己一个人在菜单里选联机存档，会提示你；再选一次，就把它变回普通存档一个人玩。
   · 房主选联机存档的时候还没人加入：游戏先开好，有人加入后存档才进入。
   · 这一次和谁玩，就按这次进来的人算，下次重新算。存档不绑定任何人。
   · 一起玩的人还没进来、或者掉线了：你刚进存档时、或者之后坐上长椅时，会被定住等对方，
     屏幕上会写着在等谁。房主正玩着的时候有人加入，房主不会当场被定住，下次坐上长椅时才等。
     等的时候没有按键能「不等了」。不想等了就暂停，回主菜单：
       - 这一次和谁玩按这次在的人算，重新进存档就不再等已经掉线、退出联机的人。
       - 只剩你一个人：照上面说的，在菜单里再选一次这个存档，就变回普通存档一个人玩。
         以后用它开房有人加入、或者用它加入别人，它又会变回联机存档。
   · 聊天框打 /coopsave 能看当前存档是不是联机存档、这次和谁一起玩；/coopsave off 把它变回普通存档。


四、出问题的话
--------------

游戏目录下 BepInEx\LogOutput.log 是日志，
出问题把它发回来就能定位。

联机存档的备份（每次一起进存档、每次加入时对齐之前都会备份，每个存档槽留最近 10 份）在：
  C:\Users\你的用户名\AppData\LocalLow\Team Cherry\Hollow Knight Silksong\一串数字\ssmp\coop-backups\
存档坏了或者对齐得不对，把那里面对应存档槽的文件发回来，就能帮你恢复。

用 /delete 删掉的存档，删之前留的那份（每个存档槽留最近 10 份）在：
  C:\Users\你的用户名\AppData\LocalLow\Team Cherry\Hollow Knight Silksong\一串数字\ssmp\deleted-saves\
删错了，把那里面对应存档槽的文件发回来，就能帮你恢复。

如果是卡在「Waiting for XXX」，日志里这两句最有用：
  Starting a check     —— 会列出三个存档 key，一眼能看出哪个对不上
  Turned down a hello  —— 说明有一条握手消息被丢掉了，以及丢的原因

两个人一起玩的时候：
  [State check]  —— 两边自动对比出来的不一样的地方
  [Hits]         —— 队友的攻击为什么没能在你这边重放
  [Replay]       —— 照跑房间那边的动作重演时出了错（每个房间每种错记一次）
  [Frames]       —— 卡顿：哪一刻卡了多久，mod 自己占了多少、是哪部分
  [Load]         —— 换房间：黑屏多久、时间花在哪一段，mod 自己占了多少
  [Stun]         —— boss 被打晕：跑房间的那边和另一边各记一次；半秒后再各记一次它头上那圈特效怎么样了，
                    “做出光圈”这一条发了没有、收到没有
  [Idle]         —— boss 超过 8 秒没出招：停在哪一步、在看哪块范围、谁在里面、它在追谁（跑房间的那边记）
  [Story]        —— 进房间 2 秒后：房间里按剧情记录决定怎么演的东西各停在哪一步，看的记录是什么值
  [Hurts]        —— 你掉血：从几格到几格、几点伤害、被什么打的
  [Damage]       —— 怪掉血：掉之前和之后的血、谁打的、联机倍数怎么除的
  [Outline]      —— 打怪描边：一场打斗从哪一下开始、为什么结束
  [Link]         —— 网络：平时每分钟一行，两个方向各到了几成；收不到对方消息的那段时间里，
                    每一秒 Steam 和 mod 各收发了多少
  [Clips]        —— 队友有几次换动作的消息没到、被补上了
  [Steam]        —— Steam 自己关于网络的提示
遇到两边不一样的情况，最好把两个人的日志都发回来。
